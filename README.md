# Calculadora

## Requisitos

- Tener instalado Java 21 o una versión posterior.
- Abrir una terminal en la carpeta donde está `calculadora.jar`.

Para comprobar que Java está instalado, ejecuta:

```powershell
java -version
```

## Ejecutar el archivo JAR

Desde la carpeta del proyecto, ejecuta:

```powershell
java -jar calculadora.jar
```

La calculadora aparecerá en la terminal. Ingresa el número de la operación y sigue las instrucciones. Para cerrar el programa, selecciona la opción `5`.

También puedes iniciar la aplicación en Windows haciendo doble clic en `calculadora.bat`.
